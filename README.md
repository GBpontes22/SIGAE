# SIGAE

Projeto acadêmico de gerenciamento de atendimentos,
desenvolvido em Python com Django e interface web.

Utiliza implementações próprias de:
- Árvore Rubro-Negra para organização por chegada.
- Min-Heap para seleção por prioridade.
- Tabela Hash para consulta por ID.

Metodologia de desenvolvimento: Extreme Programming (XP).
